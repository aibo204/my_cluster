# DGFC-v2: 密度引导洪泛聚类算法

> **Density-Guided Flood Clustering v2**
> 
> 一种基于密度峰值的自动聚类算法，专为人脸识别场景设计

## 2. 核心概念

### 2.1 局部密度 ρ (rho)

**定义**：点 i 的局部密度是其 k 近邻平均距离的倒数

```
              1
ρᵢ = ─────────────────
     mean(d_ij) + ε

其中 d_ij 是点 i 到其第 j 个邻居的距离
```

**直观理解**：

```
    高密度区域 (ρ 大)              低密度区域 (ρ 小)
    
        ●  ●                           ●
      ● ● ● ●                      
        ● ●                                    ●
      ●   ● ●                          ●
        ●                                  ●
        
    邻居距离小 → ρ 大              邻居距离大 → ρ 小
```

### 2.2 δ 值 (delta)

**定义**：点 i 到"比自己密度更高的最近点"的距离

```
δᵢ = min { d(i,j) : ρⱼ > ρᵢ }
```

**直观理解**：

```
    簇中心 (δ 大)                  普通点 (δ 小)
    
         ↑ 到更高密度点              ↑ 很近就有
         │ 的距离很远                │ 更高密度的点
         │                          │
         ●  ← 密度最高              ●
        /|\                        /
       ● ● ●                      ● ← 更高密度
      ● ● ● ●                    ●
       ● ● ●                    ●
       
    周围没有比它更密的点         附近就有更密的点
```

### 2.3 ρ-δ 决策图

**核心洞察**：真正的簇中心具有**高密度(ρ)** 且 **高δ值**

```
    δ (到更高密度点的距离)
    ▲
    │
    │  ★                      ★ = 簇中心 (高ρ + 高δ)
    │      ★         ★        ● = 簇内点 (高ρ + 低δ)  
    │                         ○ = 边界点 (低ρ + 低δ)
    │          ●●●            × = 噪声点 (低ρ + 高δ)
    │        ●●●●●●●
    │      ●●●●●●●●●●
    │    ○○●●●●●●●●●●●
    │  ○○○○○○●●●●●●                    ×
    │○○○○○○○○○○●●●
    └──────────────────────────────────────▶ ρ (局部密度)
    
    决策规则: γ = ρ × δ
    簇中心: γ > μ(γ) + k × σ(γ)
```

## 3. 算法流程

### 3.1 整体流程图

```
┌─────────────────────────────────────────────────────────────────────┐
│                        DGFC-v2 算法流程                              │
└─────────────────────────────────────────────────────────────────────┘
                                  │
                                  ▼
                    ┌─────────────────────────┐
                    │   Step 1: 构建 k-NN 图   │
                    │   时间复杂度: O(n log n) │
                    └────────────┬────────────┘
                                 │
                                 ▼
                    ┌─────────────────────────┐
                    │   Step 2: 计算局部密度 ρ │
                    │   ρᵢ = 1/mean(d_ij)     │
                    └────────────┬────────────┘
                                 │
                                 ▼
                    ┌─────────────────────────┐
                    │   Step 3: 计算 δ 值      │
                    │   δᵢ = min d(i,j)|ρⱼ>ρᵢ │
                    └────────────┬────────────┘

                         【聚类结果】
```

### 3.2 详细步骤说明

#### Step 1: 构建 k-NN 图

```python
输入: 数据点集 X = {x₁, x₂, ..., xₙ}
输出: k-NN 距离矩阵 D, k-NN 索引矩阵 I

对于每个点 xᵢ:
    找到 k 个最近邻居
    记录邻居索引和距离
```

#### Step 2: 计算局部密度

```
示例: k=5 的情况

点 A 的 5 个邻居距离: [0.1, 0.12, 0.15, 0.11, 0.13]
mean = 0.122
ρ_A = 1/0.122 = 8.2  (高密度)

点 B 的 5 个邻居距离: [0.5, 0.6, 0.55, 0.48, 0.52]
mean = 0.53
ρ_B = 1/0.53 = 1.9   (低密度)
```

#### Step 3: 计算 δ 值

```
算法伪代码:

1. 按密度 ρ 降序排列所有点: order = argsort(ρ)[::-1]
2. 对于密度最高的点: δ[order[0]] = max_distance
3. 对于其他点 i:
      在所有密度比 i 高的点中
      找到距离 i 最近的点 j
      δ[i] = distance(i, j)
      nearest_higher[i] = j   # 记录指向

示意图 (nearest_higher 链):

        ★ 密度最高 (δ=最大值)
       ↗ ↖
      ●   ●
     ↗     ↖
    ●       ●
   ↗         ↖
  ○           ○

箭头方向: 指向更高密度的最近点
```

#### Step 4: 识别密度峰值

```
计算综合评分: γᵢ = ρᵢ × δᵢ (归一化后)

自适应阈值选择:
    γ_threshold = mean(γ) + k × std(γ)
    
    其中 k = max(0.5, 2.0 - 0.3 × log₁₀(n))
    
    数据量越大, k 越小, 允许更多峰值

约束条件:
    最少峰值: √n / 5
    最多峰值: 2 × √n

示例 (n=5000):
    √5000 ≈ 70
    峰值数量范围: [14, 140]
```

#### Step 5: 洪泛填充聚类

```
核心思想: 沿着 nearest_higher 链追溯到峰值

          ★ Cluster 1              ★ Cluster 2
         ↗↑↖                      ↗↑↖
        ● ● ●                    ● ● ●
       ↗ ↑ ↖                    ↗ ↑ ↖
      ● ● ● ●                  ● ● ● ●
     ↗  ↑  ↖                  ↗  ↑  ↖
    ○  ○  ○  ○              ○  ○  ○  ○

算法:
for 每个未标记的点 p:
    沿 nearest_higher 链向上追溯
    直到到达一个已标记的点(峰值)
    将路径上所有点标记为该峰值的簇
```

#### Step 6: 验证合并相似簇

```
合并条件 (两个都要满足):

条件1: 边界重叠比例 ≥ 20%
┌─────────┐   ┌─────────┐
│ Cluster │   │ Cluster │
│    A    │●●●│    B    │
│         │   │         │
└─────────┘   └─────────┘
              ↑
           边界点

    overlap_ratio = |边界点| / min(|A|, |B|)

条件2: 簇均值余弦相似度 ≥ 0.5

    similarity = cos(mean_A, mean_B)
              = (mean_A · mean_B) / (|mean_A| × |mean_B|)

示例:
    Cluster A 均值: [0.5, 0.3, 0.8, ...]
    Cluster B 均值: [0.48, 0.32, 0.79, ...]
    similarity = 0.98 > 0.5 ✓ → 合并
    
    Cluster A 均值: [0.5, 0.3, 0.8, ...]
    Cluster C 均值: [-0.2, 0.9, 0.1, ...]
    similarity = 0.21 < 0.5 ✗ → 不合并
```

#### Step 7: 分配剩余点

```
对于未分配的点 p:
    
    找到 p 的 k 个邻居中已分配的点
    使用距离加权投票:
    
    weight(neighbor) = 1 / (distance + ε)
    
    label(p) = argmax Σ weight[label == c]
                  c

示例:
    p 的邻居:  [A, A, B, A, B]
    距离:      [0.1, 0.2, 0.15, 0.3, 0.25]
    权重:      [10, 5, 6.7, 3.3, 4]
    
    A 的总权重: 10 + 5 + 3.3 = 18.3
    B 的总权重: 6.7 + 4 = 10.7
    
    → p 被分配到 A
```

           距离矩阵 + k-NN 矩阵

## 5. 参数说明

### 5.1 主要参数

| 参数 | 默认值 | 范围 | 说明 |
|------|--------|------|------|
| `knn_k` | 30 | [10, 100] | k近邻数量，影响局部密度估计的平滑程度 |
| `density_percentile` | 0.7 | [0.5, 0.9] | 高密度点的比例阈值 |
| `merge_similarity_threshold` | 0.5 | [0.3, 0.8] | 簇合并时的相似度阈值 |
| `merge_overlap_ratio` | 0.2 | [0.1, 0.5] | 边界重叠比例阈值 |
| `radius_alpha` | 1.0 | [0.5, 2.0] | 自适应半径的缩放因子 |

### 5.2 参数调优建议

```
数据规模小 (n < 1000):
    knn_k = 20
    
数据规模大 (n > 10000):
    knn_k = 50
    
簇间距离近:
    merge_similarity_threshold = 0.7  # 提高，避免误合并
    
簇间距离远:
    merge_similarity_threshold = 0.4  # 降低，允许更多合并
```

## 9. 总结

**DGFC-v2 的核心创新**:

1. **局部密度估计**: 用 k-NN 距离倒数代替全局 GMM，适应变密度数据

2. **ρ-δ 决策图**: 借鉴密度峰值聚类思想，用 δ 值识别真正的簇中心

3. **统计阈值选择**: γ = ρ × δ 的均值 + k × 标准差，自适应确定峰值数量

4. **特征验证合并**: 合并前检查簇的特征分布兼容性，防止误合并

**优势**:
- 无需预先指定簇数量
- 能自动适应不同密度的数据
- 对噪声具有鲁棒性
- 在人脸识别场景中表现优异
